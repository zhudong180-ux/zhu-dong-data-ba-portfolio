## 0.1 智能体工程化：从"会调用大模型"到"能上线交付"

### 核心定义

```
智能体 = LLM + (检索/记忆/工具) + (计划/执行/校验) + (监控/回溯)
```

**重点不是聊天，而是"把任务做完"**。

### 五大关键原则

#### ① 流程拆解 (Workflow)
把复杂任务拆成可控步骤:每步输入输出明确、可重试、可观测、可回滚,避免 LLM 一次性胡写。

#### ② 工具调用 (Tools)
把外部能力(检索、文件处理、数据库、生成任务、权限)包装成工具:JSON Schema 约束输入输出,减少幻觉。

#### ③ 异步可靠性 (Reliability)
异步任务(task_id) + 幂等 + 超时/重试 + 限流/降级。把"生成式不确定性"变成"可运营的不确定性"。

#### ④ 评估体系 (Evaluation)
离线:基准集/回放
在线:转化率/成功率/平均耗时/失败码分布
必要时:人审抽检与回归测试

#### ⑤ 护栏 (Guardrails)
- 输入合规
- 敏感词/敏感图拦截
- 参数范围限制
- 输出格式校验
- 审计日志

### 典型架构口径

```
Router(意图/权限)
    ↓
Planner(拆步骤)
    ↓
Executor(调用工具)
    ↓
Validator(规则/安全/格式)
    ↓
Memory/Trace(日志与复盘)
```

### 成本控制

- 分层调用(小模型路由/抽取,大模型生成)
- 缓存(避免重复推理)
- 限制最大 steps/分辨率/并发
- 失败 fallback 兜底

## 🌟 算法与工程亮点

### 1. 三维装箱 (3D-Bin Packing Problem, 3D-BPP)

**业务场景**: 33 吨货车常装 20-28 吨,损失约 2000 元/车

**算法方案**: 基于**遗传算法 + 禁忌搜索 + 局部搜索**的混合元启发式

```
数学建模:
I = {1, 2, ..., n}: 待装载货物的集合
J = {1, 2, ..., m}: 可用车辆(货箱)的集合
K = {1, 2, ..., 6}: 货物允许的六种旋转朝向

约束:
- 重不压轻(Heaviest on bottom)
- 易碎品防护(Fragile protection)
- 支撑面要求(Support surface)
- LIFO(后进先出,便于多点配送)
- 体积+重量双重满载
```

### 2. 动态车辆路径问题 (DVRP) + PyVRP

**业务场景**: 末端配送"现有送货只按目的地选区域,车辆装载率仅 40%"

**算法方案**: 基于 PyVRP 的事件驱动动态路径规划

### 3. RL + ACO 混合调度框架

**MDP 建模**:
```
状态 S: {车辆状态, 订单状态, 路网状态, 约束状态}
动作 A: {派单, 插单, 重路由}
奖励 R: -(里程 + 延误 + 违约 + 风险成本)
       with action masking + reward shaping
```

**ACO 局部精炼**:
```
P(i→j) ∝ τ^α · η^β
τ_ij ← (1-ρ)·τ_ij + Σ Δτ^k_ij
```

### 4. GeoHash 空间索引 + 多因子评分

**GeoHash 召回策略**:
| GeoHash 长度 | 区域大小 | 最长距离(含 8 邻域) |
|--------------|---------|---------------------|
| 5 位 | 5km × 5km | 14km |
| 4 位 | 25km × 25km | 65km |

**多因子评分**:
```
综合分 = 0.4 × 匹配度 + 0.3 × 距离成本 + 0.3 × (空闲状态 + 历史履约)
```

### 5. "两客一危一重"风险闭环

```
识别 (Identify) → 预警 (Alert) → 干预 (Intervene) → 复盘 (Review)
```

**模型**:
- 规则引擎(可解释强)
- GBDT(预测概率)
- 异常检测(发现未知模式)
- 概率校准(阈值统一)

**指标**: 响应耗时 / 处置成功率 / 误报率 / 事故率变化
